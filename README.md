# Personal Portfolio Website

This is my **first personal portfolio website**, created while I was starting to learn web development.

The purpose of this project is to practice **HTML, CSS, and JavaScript** and create a simple website to showcase my skills, projects, and interests.

## 🚀 About the Project

This portfolio contains:

* 👨‍💻 About Me section
* 🛠️ Skills section
* 📂 Projects section
* 💬 Recommendation section
* 📧 Contact information
* 🔗 Links to my GitHub and projects

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

The HTML file contains the main structure of the portfolio and connects the CSS and JavaScript files.

CSS is used for the basic design, colors, layout, cards, and recommendation styling.

JavaScript is used to add new recommendations dynamically when the user submits one.

## 📚 What I Learned

While creating this project, I practiced:

* Creating a website using HTML
* Styling webpages using CSS
* Connecting HTML, CSS, and JavaScript
* Using JavaScript DOM manipulation
* Creating dynamic elements with JavaScript
* Creating basic cards using CSS
* Working with GitHub and Git repositories
